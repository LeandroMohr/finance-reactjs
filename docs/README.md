# Documentação do projeto

## Visão geral

Este diretório reúne as referências de produto, design e planejamento do projeto Lemo Finance.

## Arquivos principais

- DESIGN.md: identidade visual, branding, paleta e diretrizes de acessibilidade.
- PLAN.md: arquitetura, estratégia de SEO, monetização e roadmap inicial.
- ROADMAP.md: lista de calculadoras e ferramentas planejadas para as próximas entregas.
- README.md: instruções rápidas de instalação, scripts e uso do projeto no repositório raiz.

## Convenções

- Manter documentação técnica e de negócio em Markdown.
- Atualizar documentação sempre que houver mudança de arquitetura, deploy ou estratégia de produto.
- Usar este diretório para registros de decisões e documentação histórica do projeto.
